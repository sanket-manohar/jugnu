Navigation tools for go_router apps.

A Dart package that adds typed results, safe guards, typed params, tab helpers, deep links and testing helpers. And an editor extension that shows, checks and documents every route in your project.

flutter pub add jugnu

Getting started

  1. In your app folder, run flutter pub add jugnu.
  2. Import package:jugnu/jugnu.dart where you build your router.
  3. In tests, also import package:jugnu/testing.dart.
  1. Open the Extensions view and search for Jugnu for go_router.
  2. Check the publisher is sanket-manohar, then install.
  3. Open a Flutter project and select the firefly icon in the activity bar.

Requires Flutter 3.44, Dart 3.12 and go_router 18 or newer.

Features

Package

Results
pushForResult<T> and popWithResult, with a fallback after a refresh.
Guards
guards([...]) chains sync and async checks without loops.
Typed params
RouteParam.integer('id'). Values live in the URL.
Tabs
shell.switchTab keeps each stack; tap again to reset.

Extension

Routes view
Every route as a tree, one click to the code.
Completion and warnings
Real paths while you type; typos flagged with a fix.
Route diagram
A searchable map of routes and redirects.
Route reports
A password-protected PDF of routes and issues.

Manual

Guard routes and read typed params in a few lines:

final userId = RouteParam.integer('id');

final router = GoRouter(
  refreshListenable: auth,
  redirect: guards([(context, state) => auth.signedIn ? null : '/login']),
  routes: [
    GoRoute(path: '/users/:id', builder: (_, state) => UserPage(id: userId.read(state))),
  ],
);

final color = await context.pushForResult<Color>('/pick-color');

Testing

import 'package:jugnu/testing.dart';

await expectRedirect(tester, router, from: '/settings', to: '/login');
await expectDeepLink(tester, router, 'myapp://open/users/42', opens: '/users/42');

MockGoRouter records navigation for fast widget tests.

Deep links

router.deepLinks(scheme: 'https', host: 'example.com')
    .build('user', pathParameters: {'id': 42});
// https://example.com/users/42

dart run jugnu:deeplink user id=42 tab=posts --scheme myapp

Privacy

The package and the extension collect nothing: no analytics, no network requests, no stored data. Everything runs on your machine. This site has no cookies or trackers.
